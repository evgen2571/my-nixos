# Repository agent guidance

Start with [AGENTS.md](../../AGENTS.md). Load only the guidance needed for your task.
These procedures refer to human technical contracts rather than replacing them.

| Guidance | Use when |
| --- | --- |
| [task-routing](task-routing/SKILL.md) | Finding owning files and selecting checks before a change |
| [Desktop](../desktop.md) | Changing Niri, Noctalia, window rules, login, or desktop integration |
| [Neovim](../neovim.md) | Changing editor mappings, plugins, language setup, or deployment |
| [Networking](../networking.md) | Changing VPN isolation, transport, launchers, or recovery |
| [Issue tracker](../issue-tracker.md) | Reading or updating GitHub tickets |
| [Triage labels](../triage-labels.md) | Applying canonical issue labels |
| [Domain docs](../domain.md) | Resolving domain terminology or architectural decisions |

The subsystem guides remain reference pages; task routing is the reusable skill.
Instructions for people configuring Skillshare or CodeGraph belong in the
[human guides](../../docs/index.md#applications-and-desktop).
